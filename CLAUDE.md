# Project-Specific Overrides

These override the global guidelines for this repository only.

## Pushing

**Never**, ever push to GitHub in this repository as pushing is also publishing due to the nature of the project.

## Language

This quiz targets Dutch-speaking candidates for the Belgian theoretical driving exam.
User-facing documentation stays in Dutch, as an exception to the global "US English for
all documentation" rule:

- `README.md`
- `CHANGELOG.md`

Source code, comments, commit messages, and internal `docs/` (requirements, devops,
specs, ADRs, issues) still follow the global US English rule.
