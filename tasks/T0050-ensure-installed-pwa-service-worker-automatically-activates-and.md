# T0050: Ensure Installed PWA Service Worker Automatically Activates and Refreshes on New Releases

## Goals

Ensure the installed PWA picks up new releases without requiring a manual
close/reopen. `sw.js` already calls `skipWaiting()`/`clients.claim()` so a new
worker activates immediately, but the already-open client kept running old
in-memory assets and never detected updates while left open. Add a
`controllerchange` reload guard and periodic/focus-triggered update checks in
`js/app.js` so installed clients both detect and apply new releases automatically.
